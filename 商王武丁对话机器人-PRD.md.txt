# 商王武丁对话机器人 - 产品需求文档(PRD)
## 1. 文档概述
### 1.1 文档目的
本文档描述「商王武丁对话机器人」产品需求，定义产品功能、交互逻辑、用户使用场景，供开发实现前端对话页面。
### 1.2 产品简介
商王武丁对话机器人，模拟商代商王武丁身份，和用户进行对话交互。用户输入问题，机器人以武丁的口吻回复，科普商代历史、妇好相关故事，用于历史趣味交互学习。
### 1.3 用户
学生、历史爱好者，想要趣味了解商朝武丁与妇好历史的人群。

## 2. 产品功能需求
### 2.1 核心功能：对话交互
1. 用户在底部输入框输入文字问题，点击【发送】按钮提交。
2. 页面聊天框展示用户提问（右侧蓝色文字）。
3. 机器人以武丁古文风格回答，展示在聊天框左侧。
4. 聊天窗口自动滚动到最新消息。
5. 输入空内容时，点击发送，不产生任何操作。

### 2.2 页面UI界面需求
1. 页面标题：商王武丁对话机器人。
2. 聊天展示区域：边框容器，滚动条，存放全部问答记录。
3. 底部区域：文本输入框 + 发送按钮。
4. 样式：简洁白底，区分用户消息与机器人消息。

## 3. 非功能需求
1. 运行环境：浏览器打开HTML页面，无需后端服务，纯前端页面。
2. 兼容性：Chrome、Edge浏览器可正常运行。
3. 约束条件：仅支持文字问答，不支持图片、语音。

## 4. 交互流程
1. 用户打开网页，加载完成，页面展示空白聊天框与输入框。
2. 用户输入问题，点击发送。
3. 页面追加用户提问到聊天面板。
4. 机器人生成武丁风格回答，追加到聊天面板。
5. 输入框清空，聊天框自动滚动到底部，等待用户下一次提问。

## 5. 验收标准
1. 打开html页面，界面正常显示标题、聊天框、输入框、发送按钮。
2. 输入文字，点发送，可以正常显示用户消息+武丁的回复。
3. 输入空内容点击发送，不会新增消息。
4. 多条对话连续发送，聊天框可滚动，全部历史对话可见。
